# BoardMind AI

Multi-agent decision-making platform that simulates a corporate executive team.

## Project Structure

```
boardmind-ai/
├── backend/          # Python FastAPI backend
├── frontend/         # React (Vite + TypeScript) frontend
└── shared/           # Shared type definitions
```

## Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
